# 월드 탐사

RisuAI API v3용 2D·2.5D 월드 탐사 게임의 공개 배포 저장소입니다.

[플러그인 다운로드](https://mynongai.github.io/harbor-world-assets/)에서 JS 파일을 받아 Risu의 플러그인 가져오기로 설치하세요. 봇 채팅에서 **월드 탐사**를 누르면 시작합니다.

설치 파일에는 배포 주소가 포함되어 있습니다. 게임을 열 때 최신 실행 코드를 확인하며, 캐릭터·마물·도감 이미지는 필요한 화면을 처음 사용할 때 내려받습니다. 받은 파일은 기기에 보관합니다. 첫 실행과 새 에셋의 다운로드에는 인터넷이 필요합니다.

main 브랜치에 배포 파일을 push하면 GitHub Actions가 Pages를 갱신합니다. `manifest.json`에는 현재 실행 코드와 에셋의 SHA-256 해시가 기록되어 있습니다.

라이브러리 라이선스는 `LICENSES.txt`에 있습니다.
